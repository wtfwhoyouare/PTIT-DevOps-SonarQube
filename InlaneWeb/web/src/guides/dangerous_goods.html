Quy chuẩn Hàng nguy hiểm Hàng hải (IMO / IMDG Code)

Bộ luật quốc tế về vận chuyển hàng nguy hiểm bằng đường biển do Tổ chức Hàng hải Quốc tế (IMO) ban hành.

9 Nhóm phân loại hàng nguy hiểm theo công ước IMDG:

  • Class 1: Chất nổ (Explosives)
  • Class 2: Các chất khí nén, hóa lỏng hoặc hòa tan dưới áp suất (Gases)
  • Class 3: Chất lỏng dễ cháy (Flammable Liquids)
  • Class 4: Chất rắn dễ cháy, tự cháy hoặc phản ứng với nước (Flammable Solids)
  • Class 5: Chất oxy hóa và peroxide hữu cơ (Oxidizing Substances)
  • Class 6: Chất độc hại và chất lây nhiễm (Toxic & Infectious Substances)
  • Class 7: Chất phóng xạ (Radioactive Material)
  • Class 8: Chất ăn mòn (Corrosives)
  • Class 9: Hàng nguy hiểm khác (Miscellaneous Dangerous Substances)
Yêu cầu an ninh bắt buộc: Mọi container chứa hàng thuộc Class 1, 2, 7 phải được khai báo trước 48 giờ trước khi cập cảng bốc hàng.
